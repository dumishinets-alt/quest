# Відкриті дані проти корупції

Інтерактивний урок для 11 класу: відкриті дані уряду, Державний портал відкритих даних,
ProZorro, реєстри компаній, нерухомості й декларацій (ЄДР, НАЗК, YouControl, Opendatabot)
та мінірозслідування закупівель шкіл вигаданого міста Зорянськ.

Відкрийте `index.html` у браузері — збирати нічого не потрібно.

- `data.js` — усі навчальні дані (закупівлі, компанії, декларації, тести). Учитель може їх змінювати.
- `app.js` — логіка: навігація, завдання з автоперевіркою, аналітика закупівель, ризик-індикатори, звіт.
- `style.css` — оформлення (світла й темна теми).

Прогрес учня зберігається лише в його браузері (localStorage).
Усі закупівлі, компанії та особи вигадані.
